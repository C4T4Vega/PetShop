# PetShop Web — Panel de control

Panel administrativo para la gestión de la tienda **PetShop**, con operaciones **CRUD** (crear, leer, actualizar y eliminar) y registro de **auditoría** para trazabilidad de cambios sobre una base de datos en MongoDB.

## Características principales

- **Gestión CRUD:** Administración de registros del catálogo/operación de la tienda.
- **Auditoría:** Registro de acciones y movimientos realizados en el panel.
- **Acceso local rápido:** Ejecutado en entorno de desarrollo en `localhost:3000`.

## Requisitos previos

- [Node.js](https://nodejs.org/) y `npm` instalados.
- Instancia de **MongoDB**
## Pasos para ejecutar

1. **Importar la base de datos:** Subir o importar la colección inicial del proyecto a la instancia de **MongoDB**.
2. **Instalar dependencias:** En la terminal, dentro de la carpeta del proyecto, ejecuta:
   ```bash
   npm i
3. **Ejecutar web:** En terminal ejecutar: 
   ```bash
   npm start
